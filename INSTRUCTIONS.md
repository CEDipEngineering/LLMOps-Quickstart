## LLMOps Quickstart Project
This project is meant to serve as a quick way to get started with LLMOps in Databricks. Since this is very similar to MLOps, this content was based on the [MLOps Quickstart](https://github.com/databricks-solutions/mlops-quickstart)

## Claude
Please review the provided repo, as well as [this doc](https://docs.databricks.com/aws/en/machine-learning/mlops/llmops) and build the simplest, most basic (but complete) example of an LLMOps workflow.
